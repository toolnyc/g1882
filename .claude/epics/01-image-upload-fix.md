# Epic 1: Image Upload Fix

**Priority**: Critical | **Phase**: 1 — Unblock content team
**Blocks**: ALL content work (artwork, hero images, artist photos)

## Intent

Images as small as 5MB fail with "too large" errors in the Payload admin panel. This blocks the entire content pipeline — the client cannot upload artwork, artist photos, or any media until this is resolved.

## Current State

- `src/collections/Media.ts` sets `MAX_FILE_SIZE` to 50MB and validates against it
- The Payload API catch-all route at `src/app/(payload)/api/[...slug]/route.ts` is auto-generated by `@payloadcms/next` — it exports no `config` for body size
- Next.js App Router defaults to ~1MB body size for route handlers
- The 50MB validation in Media.ts is never reached because the request is rejected earlier
- No `vercel.json` exists to set function-level limits
- Media collection accepts `image/*`, `video/mp4`, `video/webm`
- Uploads go to Vercel Blob storage
- Image processing generates 7 size variants + WebP conversion

## Delta

1. **Diagnose** where the body size limit is enforced — investigate `@payloadcms/next` config, `vercel.json` functions config, Payload adapter options, and `next.config.js` `serverActions.bodySizeLimit`
2. **Apply body size override** — target 50MB to match `MAX_FILE_SIZE`. Most likely via `vercel.json` functions config or a Payload-native setting
3. **Set function timeout** — image processing (resize + WebP + 7 variants + Blob upload) on a 50MB file will exceed default timeout. Set `maxDuration` explicitly
4. **Test** uploads at 5MB, 20MB, and 50MB on preview deployment through admin panel

## Data Model

No schema changes. Media collection already supports the intended file types and sizes.

## UI Breakdown

No UI changes. Fix is infrastructure/config only.

## Acceptance Criteria

- [ ] 5MB image uploads successfully through admin panel
- [ ] 20MB image uploads successfully through admin panel
- [ ] 50MB image uploads successfully through admin panel
- [ ] All 7 image variants generate correctly for large uploads
- [ ] Payload's 50MB limit is enforced with a clear error message for oversized files
- [ ] 2560px auto-resize cap still applies
- [ ] Works on preview deployment (Vercel)

## Known Risks

- The catch-all route is auto-generated — can't modify it directly; Payload regenerates it
- `serverActions.bodySizeLimit` may not apply to route handlers (only server actions)
- Function timeout may need to be higher than default for 50MB files with 7 variants
- Vercel Blob has its own upload size limits to verify
